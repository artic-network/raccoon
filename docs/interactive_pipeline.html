One or more sequence files in FASTA format

FASTA format consists of a header line starting with ">" followed by the sequence data.

A file can contain multiple sequences, each with its own header.

Metadata file(s)

CSV or TSV files with sequence metadata (optional).

Each file should contain a header row with column names and subsequent rows with metadata for each sequence.

Metadata files should have a column that can be used to match the provided sequence IDs (default: "sample").

Ideally, the metadata file(s) should also contain location and date information for each sequence.

raccoon seq-qc

Purpose

Combine and harmonize sequence headers across one or more input files. Creates structured, consistent sequence headers using metadata, and filters sequences by length and N-content.

Basic Usage

raccoon seq-qc -f file1.fasta file2.fasta -o combined.fasta

With Metadata

raccoon seq-qc -f *.fasta -m metadata.csv \
--metadata-id-field sample_id \
--header-fields "{sample}|{admin1}|{admin2}|{date}" \
-o combined.fasta

Key Options

  • -f, --fasta: Input FASTA file(s) (required)
  • -m, --metadata: Metadata CSV/TSV files (optional)
  • --header-fields: Sequence header template
    (default: {sample}|{location}|{date})
  • --min-length: Minimum sequence length filter
  • --max-n-content: Maximum N-content proportion (0-1)
  • --require-date: Require a valid date in the metadata or sequence header
  • -o, --outfile: Name of combined output FASTA file
    (default: `combined.fasta`)

Customisation

  • --metadata-id-field: Field in metadata to use as unique identifier
    (default: `sample`)
  • --metadata-location-field: Field in metadata to use for location information
    (default: `location`)
  • --metadata-date-field: Field in metadata to use for date information
    (default: `date`)
  • --seq-id-field-index: Which field in the FASTA header to match against metadata
    (default: whole header)
  • --seq-id-delimiter: Delimiter used to split FASTA header fields
    (default: `|`)
  • --require-date: Require a valid date in the metadata or sequence header

Outputs

  • Combined FASTA file with harmonized headers
  • HTML report with seq-qc summary
  • Missing metadata CSV flagging sequences with missing location or date metadata
  • CSV file of sequences that did not pass filters, and so are not included in the combined FASTA

raccoon aln-qc

Purpose

Assess alignment quality and flag problematic sites. Detects clustered SNPs, SNPs adjacent to gaps or Ns, and frame-breaking indels. Generates a mask file for downstream masking.

Basic Usage

raccoon aln-qc alignment.fasta -d outdir

With GenBank Reference

raccoon aln-qc alignment.fasta -d outdir \
--genbank reference.gb \
--reference-id ref_seq_id

Key Options

  • alignment: Input alignment FASTA (positional, required)
  • -t, --sequence-type: nt or aa (default: nt)
  • --cluster-window: Window size for clustered SNP detection (bp)
  • --cluster-count: Min SNPs in window to flag as clustered
  • --max-n-content: N-content threshold for flagging
  • --no-flag-*: Skip specific flag types (clustered, n-adjacent, gap-adjacent, frame-break)

Outputs

  • mask_sites.csv - Flagged sites with flag types
  • aln-qc_report.html - Interactive alignment report
  • alignment_flags.tsv - Per-sequence flag details
  • alignment_summary.txt - Summary statistics

raccoon mask

Purpose

Apply an alignment QC mask file to exclude flagged sites from downstream phylogenetic inference. Replaces flagged sites with a mask character (default: ?).

Usage

raccoon mask alignment.fasta \
--mask-file mask_sites.csv \
-d outdir \
-o alignment.masked.fasta

Key Options

  • alignment: Input alignment (positional, required)
  • --mask-file: Mask CSV from aln-qc (required)
  • --mask-character: Character for masking (default: ?)
  • -t, --sequence-type: nt or aa (default: nt)

Note

This step is optional. You can proceed directly to tree building if you prefer to retain all sites.

raccoon tree-qc

Purpose

Assess phylogenetic tree quality and identify problematic sequences. Detects long branches, convergent mutations, APOBEC3-mediated and ADAR-induced mutations, and evaluates temporal signal.

Basic Usage

raccoon tree-qc --tree alignment.treefile -d outdir

With ASR and Bias Detection

raccoon tree-qc --tree alignment.treefile \
--alignment alignment.fasta \
--asr-state alignment.state \
-d outdir \
--run-adar --run-apobec

Key Options

  • -t, --tree: Tree file (required)
  • --outgroup-ids: Comma-separated outgroup sequence IDs (optional)
  • --alignment: Alignment FASTA (needed for some analyses)
  • --asr-state: ASR file from IQ-TREE
  • --long-branch-sd: SD threshold for long-branch flagging (default: 3.0)
  • --run-adar: Run ADAR mutation detection
  • --adar-window: Window size for ADAR clustering (default: 300 bp)
  • --run-apobec: Run APOBEC3 mutation detection
  • --midpoint-root: Midpoint-root tree for visualization

Outputs

  • tree_qc_report.html - Interactive tree visualization
  • flagged_sequences.txt - Outlier sequences for removal
  • convergent_mutations.csv - Detected convergent mutations
  • tree_summary.txt - Summary statistics

MAFFT - Multiple Sequence Alignment

Purpose

MAFFT is an external multiple sequence alignment software. It aligns the combined sequences into a format suitable for phylogenetic inference.

Installation

conda install -c bioconda mafft

Basic Usage

mafft --auto input.fasta > alignment.fasta

Common Options

  • --auto: Automatic method selection based on input size
  • --thread: Number of threads for parallelization
  • --maxiterate: Number of refinement iterations

Note

External tool: Not part of raccoon, but essential for the pipeline. Install separately using Conda or your package manager.

Citation

Katoh K, Standley DM. MAFFT multiple sequence alignment software version 7: improvements in performance and usability. Mol Biol Evol. 2013 Apr;30(4):772-80. doi: 10.1093/molbev/mst010. Epub 2013 Jan 16. PMID: 23329690; PMCID: PMC3603318.

IQ-TREE - Phylogenetic Inference

Purpose

IQ-TREE is an external software for maximum likelihood phylogenetic tree estimation. It can also generate ancestral state reconstructions for use with tree-qc.

Installation

conda install -c bioconda iqtree

Basic Usage

iqtree -s alignment.fasta -m GTR+G -bb 1000

Common Options

  • -s: Input alignment file
  • -m: Evolution model (e.g., GTR+G, HKY+F)
  • -bb: Number of bootstrap replicates
  • -asr: Compute ancestral state reconstruction
  • -T: Number of threads

Citation

Minh, B.Q., Schmidt, H.A., et al. IQ-TREE 2: New Models and Efficient Methods for Phylogenetic Inference in the Genomic Era. Molecular Biology and Evolution, Volume 37, Issue 5, May 2020, Pages 1530–1534, https://doi.org/10.1093/molbev/msaa015

For Raccoon Integration

To generate ASR files for tree-qc analysis, use flag -asr in IQ-TREE. This will create a .state file needed for advanced tree-qc analyses.
